Section 1

Repository Layout and Dependency Hub

A central library anchors database models across the fleet.

Standard src/ layout

gmsshared/
├── setup.py                # Defines the "gmsshared" package & dependencies
├── src/
│   ├── config.py           # Centralized 12-factor environment loading
│   ├── database.py         # SQLAlchemy engine and session management
│   ├── models/             # The "Single Source of Truth" for DB tables
│   │   ├── user.py
│   │   ├── membership.py
│   │   └── _ref_*.py       # Reference/Lookup tables
│   ├── util/               # Shared logic: datetime, validators, enums
│   └── web/                # FastAPI glue: auth decorators, response helpers
└── gms-base.Dockerfile     # The foundation for all GMS service images

Centralized Dependencies

setup(
    name="gmsshared",
    version="1.0.0",
    package_dir={"": "src"},
    packages=find_packages(where="src"),
    install_requires=[
        "fastapi",
        "sqlalchemy",
        "pydantic-settings",
        "celery",
        "python-jose[cryptography]", # For JWT logic in web/
        "pandas",                   # For reports/ and batch-worker/
    ],
)

Hub-and-spoke imports

# Inside any service (e.g., members-service)
from gmsshared.config import get_config
from gmsshared.models.user import User
from gmsshared.web.fastapi_glue import fastapi_create_response

Shared Base Strategy

Pre-building dependencies into a base image keeps deployment pipelines fast.

Shared Base Image

Inheriting gms-base

# auth-admin-service/Dockerfile
FROM gms-base

COPY ./auth-admin-service/ /app/auth-admin-service
# We use --no-deps because gms-base already has everything
RUN pip install --no-deps -e /app/auth-admin-service

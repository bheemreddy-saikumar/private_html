Service Layer Implementation

Plaintext credentials must be hashed before touching persistence.

Configuring CryptContext

# Conceptual Service Layer Pattern for Password Hashing
from passlib.context import CryptContext

# Configure CryptContext with a strong, modern hashing algorithm.
# 'argon2' is specified; 'deprecated="auto"' ensures compatibility with older
# hash formats while favoring the modern scheme.
pwd_context = CryptContext(schemes=["argon2"], deprecated="auto")

def get_password_hash(password: str) -> str:
    """
    Hashes a plaintext password using the configured secure hashing algorithm.
    This function should be called when a new password is set or changed.
    """
    return pwd_context.hash(password)
